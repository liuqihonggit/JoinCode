## 问题清单

### 问题1：gh_release_list 输出原始 API JSON（中严重度）✅ 已修复

- **位置**: `services/Mcp/src/GitHub/GitHubToolHandlers.Release.cs:24`
- **现象**: `gh_release_list` 直接返回 GitHub REST API 原始 JSON，包含大量冗余 URL（assets_url, upload_url, html_url, author.url, author.avatar_url 等 15+ 个冗余字段）
- **根因**: `GhReleaseListAsync` 直接 `Ok(result.Body)` 返回原始响应，未像 `SummarizeRepoList`/`SummarizeRunList` 那样精简
- **影响**: 与第一轮问题2（gh_repo_list/gh_run_list 已修复）同类，输出冗长词不达意
- **修复方案**: 新增 `SummarizeReleaseList` 方法，只保留 id/tag_name/name/draft/prerelease/created_at/published_at/assets(name+size)
- **ADR 0080 情况**: 5 (词不达意)
- **修复提交**: `70478f520` fix: gh_release_list输出精简JSON去掉冗余URL和author对象
- **验证**: 修复后输出 `[{"id":384974240,"tag_name":"test-adr0080-v0.0.1","name":"ADR0080 测试 Release","draft":true,"prerelease":false,"created_at":"2026-09-08T18:37:36Z","published_at":null,"assets":[]}]` ✅

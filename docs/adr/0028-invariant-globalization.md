# 0028. InvariantGlobalization 渐进式双语策略

- 状态：accepted
- 日期：2026-08-29
- 决策者：项目架构组

## 背景

项目目标为 NativeAOT 单文件发布（ADR 0002）。.NET 全球化资源（`icu.dat`）体积大（~10MB），包含所有语言的文化数据。CLI 工具仅需中英文，不需要完整全球化资源。

## 决策

1. **`InvariantGlobalization=true`**：Release 模式 Exe 项目强制启用，不携带 ICU 数据
2. **渐进式双语（中英文）**：遇到全球化问题时逐步实现，不必一次性处理完
3. **字符串比较/排序**：用 `StringComparer.Ordinal`（序数比较），不依赖文化敏感比较

## 替代方案

1. **完整全球化（携带 ICU）**：放弃。发布体积增加 ~10MB，CLI 单文件目标受影响。
2. **仅中文**：放弃。错误信息、日志需英文便于国际社区排查。
3. **一次性全量双语**：放弃。工作量大，渐进式更务实。

## 后果

- 正面：发布体积小；AOT 兼容；启动快
- 负面：文化敏感操作（如日期格式化、排序）需手动处理，不能用 `CultureInfo.CurrentCulture`
- 中性：中英文混合展示，渐进式完善

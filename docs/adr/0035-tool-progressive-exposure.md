# 0035. 工具渐进式暴露

- 状态：accepted
- 日期：2026-08-29
- 决策者：项目架构组

## 背景

项目有 296 个工具（ADR 0014），一次性向 LLM 暴露所有工具的 schema 会消耗大量 token，且 LLM 可能误用不相关工具。需要策略控制工具暴露面。

## 决策

**工具渐进式暴露**：

- `tool_groups` 拥有一切非 System 工具（含 OnError）
- 失败时报错时披露完整 schema 文本
- 正常时只暴露当前相关的工具组

定位文件：`docs/design/工具渐进式暴露设计.md`

## 替代方案

1. **一次性暴露所有工具**：放弃。296 工具的 schema 消耗大量 token，LLM 误用率高。
2. **按固定分组暴露**：放弃。无法根据上下文动态调整，不够灵活。
3. **完全按需暴露（LLM 请求才给）**：放弃。LLM 不知道有哪些工具可请求，需预暴露组名。

## 后果

- 正面：token 消耗可控；LLM 误用率低；工具暴露面按上下文调整
- 负面：失败时才披露完整 schema，可能增加错误恢复的 token 消耗
- 中性：tool_groups 包含 OnError 工具，错误恢复时可用

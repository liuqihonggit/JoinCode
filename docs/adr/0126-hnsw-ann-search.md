# 0126. HNSW 近似最近邻搜索替代暴力搜索

- 状态：proposed
- 日期：2026-10-01
- 决策者：用户 + AI

## 背景

当前向量搜索使用 `BruteForceAnn`（暴力搜索），遍历全部向量计算余弦相似度，复杂度 O(N)。

6004 块 × 768 维规模下暴力搜索 < 1ms（SIMD 加速），性能足够。但随着项目增长（50000+ 文件 → 50000+ 块），暴力搜索会线性变慢。

`IAnnSearch` 接口已预留替换为 HNSW 等近似算法。

## 决策

实现 HNSW (Hierarchical Navigable Small World) 替代暴力搜索。

### 算法

HNSW 是多层图结构：
- 上层稀疏（快速定位），下层密集（精确搜索）
- 插入：随机分配层级，从上层到下层逐层插入并连接邻居
- 搜索：从最上层贪心搜索到 efSearch 个候选，逐层向下细化

### 参数

| 参数 | 值 | 说明 |
|------|------|------|
| M | 16 | 每层最大连接数（第0层 = 2M = 32） |
| efConstruction | 200 | 建图时搜索宽度 |
| efSearch | 50 | 搜索时搜索宽度 |
| mL | 1/ln(M) | 层级分配概率参数 |

### 复杂度

| 操作 | 暴力搜索 | HNSW |
|------|----------|------|
| 插入 | O(1) | O(M × efConstruction × log N) |
| 搜索 | O(N) | O(efSearch × log N) |

6004 块规模下 HNSW 搜索 ~0.1ms vs 暴力 ~1ms（10x 加速）。50000 块规模下 HNSW ~0.2ms vs 暴力 ~8ms（40x 加速）。

## 替代方案

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| 保持暴力搜索 | 简单、零依赖 | O(N) 线性增长 | ❌ 大规模瓶颈 |
| 用 NuGet 包（HNSWLib） | 成熟 | 可能不支持 NativeAOT | ❌ AOT 约束 |
| 自己实现 HNSW | AOT 兼容、无依赖、可控 | 实现复杂 | ✅ 采用 |

## 约束

- 纯 C# 实现，无外部依赖
- NativeAOT 兼容（禁止反射 emit、dynamic）
- 线程安全（读操作无锁，写操作互斥）
- 实现 `IAnnSearch` 接口，与 `BruteForceAnn` 可互换

## 验收

- 编译通过 + 单元测试通过
- 重建索引后搜索结果与暴力搜索一致（召回率 > 95%）
- 搜索延迟 < 暴力搜索延迟

### 问题6 详情
- 根因: FileWriter.WriteFileWithLockAsync 默认用 Encoding.UTF8(带BOM); FileEncodingDetector 对无BOM文件也返回带BOM编码
- 修复: 两处默认编码改为 new UTF8Encoding(false); 有BOM文件仍返回Encoding.UTF8保持原编码
- 验证: 3个BOM单元测试 + 15个编码检测测试 + 151个IO测试 + 490个Services测试全通过

### 问题7 详情
- 根因: 插值字符串 {record?.SuccessRate:P1 ?? 0:P1} 格式部分被解析为非法格式
- 修复: 改为 {(record?.SuccessRate ?? 0):P1} 先空合并再格式化
- 验证: 33个ToolScore/ToolHealth测试全通过

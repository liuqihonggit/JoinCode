# 任务：P3 聊天体验增强（渲染/搜索/编辑/错误/统计/命令辅助）

## 背景
P2 已闭环（88 测试绿）：会话历史持久化、模型切换真实化、权限确认 UI。本任务从真实聊天体验缺口出发，规划 8 项增强，按里程碑逐步交付。

## 子任务（用户选定，优先级从高到低）
| # | 子任务 | 现状 | 目标 |
|---|--------|------|------|
| P3-1 | Markdown 渲染 | 正文纯文本 + 简易代码块识别（IsCodeBlock 用 Consolas） | 引入 Markdig/Avalonia.Markdown 渲染代码块/列表/表格，代码高亮 |
| P3-2 | 会话列表搜索 | 消息有搜索（FilteredMessages）但侧边栏会话无搜索 | 侧边栏会话搜索框，关键词过滤会话 |
| P3-3 | 消息编辑重发 | 已发送用户消息不可编辑 | 编辑用户消息 → 重发（等价于替换该轮后重发） |
| P3-4 | 错误消息展示 | 仅 StatusText 标红 | 引擎异常友好错误气泡 + 重试入口 |
| P3-5 | 会话用量统计 | 仅当前会话 CharsCount/EstimatedTokens | 每会话 token/字符用量统计显示在侧边栏/状态栏 |
| P3-6 | 命令补全提示框 | 输入框无命令感知 | 输入 `/` 时弹出命令补全列表，方向键选择+Enter 填入 |
| P3-7 | 命令中文提示 | 无命令体系 | 命令带中文描述（tooltip/列表展示） |
| P3-8 | 热命令统计排序 | 无 | 按使用频率对命令排序（高频前置） |

## 架构约束（必须遵守）
- `JoinCodeGui.csproj` 仅引 Abstractions + Composition + Pipelines；UI 层不触碰引擎内部
- Markdown 包需 AOT 兼容：先查 nuget 是否支持 NativeAOT，必要时建卫星项目验证（AGENTS.md：复杂任务网络查询 nuget 包支持 AOT）
- 消息编辑/错误展示走 `IJccChatSession` 门面，不在 UI 层解析引擎类型
- 命令体系：GUI 本地命令列表（无引擎依赖）→ 命中 `InputText` 前缀 `/` 触发补全
- 每个里程碑：红测试 → 实现 → 编译 → 绿测试 → 文档 → git 提交

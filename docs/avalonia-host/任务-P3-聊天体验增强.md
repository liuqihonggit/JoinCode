## 架构约束（必须遵守）
- `JoinCodeGui.csproj` 仅引 Abstractions + Composition + Pipelines；UI 层不触碰引擎内部
- Markdown 包需 AOT 兼容：先查 nuget 是否支持 NativeAOT，必要时建卫星项目验证（AGENTS.md：复杂任务网络查询 nuget 包支持 AOT）
- 消息编辑/错误展示走 `IJccChatSession` 门面，不在 UI 层解析引擎类型
- 命令体系：GUI 本地命令列表（无引擎依赖）→ 命中 `InputText` 前缀 `/` 触发补全
- 每个里程碑：红测试 → 实现 → 编译 → 绿测试 → 文档 → git 提交

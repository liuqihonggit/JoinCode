# 任务：GUI 温度/长度/提示词接入引擎

## 背景
GUI 设置面板的温度/最大长度/系统提示词目前是**占位属性**（MainViewModel 仅本地存储，未传入引擎）：
- `Temperature`（滑块 0-2，默认 0.7）
- `MaxTokens`（滑块 256-32768，默认 4096）
- `SystemPrompt`（TextBox，默认"你是 JoinCode 助手…"）

**引擎消费链**（已确认）：
- 温度/长度：`ChatOptionsFactory.Create()`（`core/execution/Brain/src/Context/Services/Prompt/ChatOptionsFactory.cs`）用**固定** `LlmParameters.Chat`（温度 0.7 / MaxTokens 2000），无运行时配置源
- 系统提示词：CLI 用 `IChatService.SetSystemPromptAsync`（经 admin 管道，`SystemPromptApplyStep` 在启动时应用一次）

## 目标
1. **SystemPrompt 接入**（低风险）：`IJccChatSession` 暴露 `SetSystemPromptAsync`，VM 在发送前应用编辑后的提示词
2. **温度/长度接入引擎**：为 `ChatOptionsFactory` 提供可配置源，GUI 滑块变更真实生效；CLI 默认行为不变

## 架构约束
- `ChatOptions` 的 `Temperature`/`MaxTokens` 是可空 init（`foundation/Abstractions/01-ai/LLM/Execution/ChatOptions.cs`）
- `IExecutionSettingsProvider`（Abstractions）当前含 EffortLevel/FastMode/FastModelId
- CLI 无运行时温度/长度命令 → 扩展 ExecutionSettingsProvider 加 `Temperature?`/`MaxTokens?`，CLI 不设（null）→ `ChatOptionsFactory` 回退 `LlmParameters.Chat`，行为不变
- SystemPrompt 复用 `IChatService.SetSystemPromptAsync`（admin 管道，保留审计），对齐 CLI `SystemPromptApplyStep`

# 任务：中间件管道共享工程化（P1-1 前置）

## 背景
GUI 接入真实引擎时 `IChatService` 依赖 17 条中间件管道，但生产管道注册 `AddAllPipelines` 位于 `app/JoinCode`（Exe），GUI 不应引用 Exe。测试工程用 `TestPipelineRegistration`（241 行）复制了一份 —— 造成两套实现漂移。方案：抽共享管道工程，CLI/GUI/测试统一复用。

## 已确认决策
- 共享工程位置：`composition/` 下（与 Composition/Clock 并列，组合层）
- 4 个 CLI 独有中间件（Timing/ErrorHandling/Audit/TokenBudget）移入共享工程并一起用 —— 经核实为纯引擎中间件，零 CLI 依赖
- 管道覆盖：全量 17 条（GUI 虽只需 Chat/ChatInit/ChatAdmin，但全量相等复制 `AddAllPipelines` 保证与 CLI 零差异）
- 令牌陷阱：CLI 与 Query 各有一个 `TokenBudgetMiddleware`，靠别名区分（`ChatTokenBudgetMiddleware` / `QueryTokenBudgetMiddleware`），迁入共享工程必须保留别名

# GUI 外观与动效方案

保留 Avalonia 桌面架构和现有 session 门面。界面支持四个基础主题，叠加八种强调色；强调色配置通过嵌入 JSON 读取，由源码生成 JsonContext 解析，不加入 GUI 专属主题到 CLI 枚举。

外观设置保存在 gui-preferences.json。GUI 的 Solarized 选择保留原枚举值，同时向引擎映射基础明暗。外部引擎主题改变仅在明暗真正改变时覆盖 GUI 主题，避免引擎同明暗回声覆盖 Solarized。

动效采用 Avalonia 原生过渡：控件背景、描边、透明度、按下缩放；设置抽屉宽度过渡；忙碌指示淡入淡出。统一由 AnimationsEnabled 开关控制，不影响真实任务计时器。

会话筛选消费已有 Sessions 集合，监听集合和标题变更，不拷贝会话对象。标题查询不区分大小写、不改变当前会话、不触发引擎调用。

布局采用固定宽度侧栏，主区随窗口伸缩；顶部工具栏允许横向滚动以避免较窄窗口裁掉操作。空状态提示绑定真实发送快捷键。

替代方案：重写为 Web GUI 会割裂现有桌面门面和持久化；新增 CLI 主题会把仅涉及 GUI 的配色扩散到引擎；无限装饰性循环动效会干扰代码阅读。均不采用。

验证发现 Solarized 原始文字和按钮前景对比度不满足 AA，保留背景色调，提高文字亮度/深度，统一实底按钮为白字。强调色同时驱动 FluentTheme.Palettes，滑块和开关与自定义控件保持一致。

界面新增 Markdown 文件保存，使用系统保存对话框选择目的地；保留正文 Markdown 与代码块、跳过系统提示词注入；导出完整会话，不受搜索过滤影响。

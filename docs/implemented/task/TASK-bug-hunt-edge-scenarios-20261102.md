## 修复的问题

### J1 超长响应注入超时（测试基础设施）
- **根因**: `BuildOpenAiStreamChunks` 逐字符生成 6000+ chunk，HTTP 注入超时
- **修复**: 改为按行发送，100 行只需 100 chunk

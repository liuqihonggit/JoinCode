# 子智能体摘要炸窗防护设计

> 状态：设计阶段（待确认后落地）
> 日期：2026-08-08
> 背景：子智能体返回的摘要若超过主智能体上下文窗口剩余大小，主智能体炸窗报错停止，且无渐进式压缩。

---

## 1. 问题根因

子智能体（Task 工具）的输出经 `BuiltInAgentToolHandlers` 的 5 处 `ToolResultBuilder.Success().WithText(result.Output).Build()` **原样**塞回主智能体：

| 方法 | 文件:行 |
|---|---|
| `PlanAgentAsync` | `core/ai/Agents/src/ToolHandlers/BuiltInAgentToolHandlers.cs:51` |
| `ExploreAgentAsync` | 同上:92 |
| `VerificationAgentAsync` | 同上:133 |
| `GeneralAgentAsync` | 同上:173 |
| `GuideAgentAsync` | 同上:213 |

`SubAgentResult.Output` 是子智能体 LLM 流的纯文本拼接，无任何截断/结构化包装。

现有上下文保护链路（`ChatContextManager` 四级：Preflight 0.95 → AfterUsage 0.5/0.7/0.8 → `SnipStaleToolResults` 头尾40行 → `ContextFoldExecutor.FoldAsync` head摘要+tail保留 + `MicrocompactService`）都作用在**已追加的历史**上。若**单条 ToolResult 本身就大于剩余窗口**，折叠（对历史摘要）无法容纳这条新消息，发送即炸窗。

**结论**：缺单条工具输出级别的防护 + 子智能体输出无结构化包装。

## 2. 现状对比

### 2.1 当前项目（w1 / JoinCode）

| 能力 | 有无 | 位置 |
|---|---|---|
| 单条工具输出落盘兜底 | ❌ 无 | — |
| 子智能体输出结构化包装 | ❌ 纯文本 | `BuiltInAgentToolHandlers` |
| 历史折叠（head摘要+tail保留） | ✅ | `ContextFoldExecutor` |
| 微压缩（工具结果占位） | ✅ | `MicrocompactService` |
| 过期工具结果剪裁 | ✅ 头尾40行 | `SnipStaleToolResults` |
| Preflight 预判 | ✅ 0.95 | `ContextFoldDecider.DecidePreflight` |
| Token 估算 | ✅ 字符/4 | `ContextFoldDecider.EstimateTokenCount` |

### 2.2 openCode（anomalyco/opencode）调研

| 层 | 文件 | 机制 |
|---|---|---|
| L1 Truncate | `src/tool/truncate.ts` | 工具输出超 `2000行/50KB` → 完整落盘 `truncation-dir/tool_{id}`（留7天），返回**预览+指针**：`"Full output saved to: {file}\nUse Grep/Read…"` |
| L2 Overflow 检测 | `src/session/overflow.ts` | `total_tokens >= usable(=input_limit - 20000)` → 触发压缩 |
| L3 Compaction | `src/session/compaction.ts` | `prune`(旧工具结果标compacted，保护40k/门槛20k) + `select`(head/tail，tail最近2轮，预算usable*0.25 clamp 2k~8k) + `serialize`(工具输出截2000字符) + 专用 compaction agent 生成摘要替换head |
| L4 兜底报错 | compaction.ts 内 | `ContextOverflowError("too large to compact")` 停止 |

openCode 的子智能体 `task_result` 用 `<task id state><summary><task_result>{text}</task_result></task>` XML 包装（`src/tool/task.ts` 的 `renderOutput`），但**不截断**，靠通用 Truncate + parent compaction。

**openCode 哲学**：不特殊处理子智能体摘要，当普通工具输出走统一 Truncate(落盘兜底) + Compaction(历史压缩)。允许半截预览，因完整落盘可取。

## 3. 最强方案：5 层防御

结合两者长处，补两者短板。子智能体产出 `O`，主智能体剩余预算 `R = ctxMax - currentTokens - reserve`。

| 层 | 触发 | 动作 | 来源 | 不半截 |
|---|---|---|---|---|
| **L0 结构化包装** | 总是 | `O → <task id state><summary>一句</summary><result>O</result></task>`。summary 复用 `AgentSummaryService` 扩展一句话 | 学 openCode `renderOutput` | — |
| **L1 直接放** | `len(O) ≤ R` | 原样 `WithText(O)` | 现状 | ✅ |
| **L2 自摘要** ★新增 | `len(O) > R` | 子智能体基于完整 O 调一次 LLM 压成 `≤ R` 连贯摘要 S。`S ≤ R` → 放 S | 新增（两者都无） | ✅ 连贯摘要 |
| **L3 落盘指针兜底** ★新增 | L2 失败/仍超 | 完整 O 落盘 `.xxx/subagent/{id}.md`，只返回指针+一句话 summary（**不返回半截预览**）：`"[子智能体 {id} 报告 {n}行/{t}token，概要：{summary}。完整存档 {path}，read 查看]"` | 学 openCode Truncate，去掉半截预览 | ✅ 只看指针 |
| **L4 历史压缩** | 主智能体整体溢出 | 复用 `MicrocompactService` + `ContextFoldExecutor.FoldAsync` + `SnipStaleToolResults`，对齐 openCode prune 阈值（保护40k/门槛20k） | 当前项目已有，调阈值 | ✅ |
| **L5 兜底报错** | L4 救不了 | `ContextOverflowError` 退出 | 学 openCode | — |

### 3.1 时序

```
子智能体完成，产出 O
  ↓ L0 包装
  ↓ 算剩余预算 R
  ↓ len(O) ≤ R？
     ├─ 是 → L1 直接放 O（最常见，零成本）
     └─ 否 → L2 自摘要（可选，默认开）
              ├─ S ≤ R → 放 S（连贯，不落盘）
              └─ 失败/仍超 → L3 落盘指针（永不炸窗）
  ↓ 进入主智能体历史
  ↓ L4 整体溢出？→ 复用现有折叠链路
  ↓ L5 还溢出 → ContextOverflowError
```

### 3.2 比两者强在哪

| 对比 | 当前项目 | openCode | 本方案 |
|---|---|---|---|
| 单条超大防护 | ❌ 炸窗 | ✅ Truncate 落盘 | ✅ L3 |
| 中等超限 | ❌ 无 | 落盘（LLM 多 read） | ✅ L2 自摘要直接放 |
| 半截问题 | — | 允许半截预览 | ✅ L3 只给指针 |
| 历史压缩 | ✅ 四级 | ✅ compaction agent | ✅ 复用+对齐prune |
| 结构化 | ❌ 纯文本 | ✅ XML | ✅ L0 XML+summary |
| 额外 LLM 调用 | 0 | 0 | L2 一次（可配置关） |

## 5. 契约变更

### 5.1 SubAgentResult 扩展

```csharp
public sealed class SubAgentResult
{
    public required string AgentId { get; init; }
    public bool IsSuccess { get; init; }
    public required string Output { get; init; }
    public string? Error { get; init; }
    public long? ExecutionTimeMs { get; init; }
    public CacheSafeParams? CacheSafeParams { get; init; }

    // 新增
    public string? Summary { get; init; }        // L0 一句话概要
    public string? ArchivedPath { get; init; }   // L3 落盘路径（null=未落盘）
    public bool IsCompacted { get; init; }       // true=走了 L2/L3
}
```

### 5.2 L0 包装格式

```xml
<task id="{AgentId}" state="{completed|error}">
<summary>{一句话}</summary>
<task_result>{O 或 S 或 指针}</task_result>
</task>
```

### 5.3 L3 指针格式（不半截）

```
[子智能体 {id} 报告 {n}行/{t}token，概要：{summary}。完整存档 {path}，read 查看]
```

## 6. 配置项

| 配置 | 默认 | 说明 |
|---|---|---|
| `SubAgent:Summary:Auto` | `true` | L2 自摘要开关。关则跳过 L2，中等超限直接落盘 |
| `SubAgent:Summary:MaxRetries` | `1` | L2 LLM 调用失败重试 |
| `SubAgent:Archive:Dir` | `.xxx/subagent` | L3 落盘目录 |
| `SubAgent:Archive:RetentionDays` | `7` | 落盘文件保留天数（学 openCode） |
| `SubAgent:ReserveTokens` | `20000` | 算 R 时的 reserve（学 openCode COMPACTION_BUFFER） |
| `ContextFold:PruneProtect` | `40000` | L4 prune 保护阈值（对齐 openCode） |
| `ContextFold:PruneMinimum` | `20000` | L4 prune 门槛（对齐 openCode） |

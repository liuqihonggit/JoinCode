# 强迫症扁平化方案 — 命名规范 + 同名层级消除 + 助手文件夹

> 创建: 2026-09-12

## 一、命名强规范

| 规则 | 说明 |
|------|------|
| 文件夹 | 全小写 + 下划线分隔，禁止驼峰/连字符/空格/中文 |
| 文件 | 大驼峰（PascalCase），禁止符号（除 .cs/.csproj 等扩展名） |
| 同名层级 | 禁止 aa/aa/ 模式（move 命令频繁出错） |
| 前缀提升 | 同名层级用父级前缀提升：abs_core/Core/Clock/ → abs_core/core_clock/ |
| 文件夹上限 | 一个文件夹下不超过 30 个子文件夹 |
| 纯净性 | 文件夹下不能文件夹和文件混排 |

### 2.3 abs_core/Pipeline/Core/ 提升

Pipeline/Core/ 下都是 .cs 文件（IMiddleware.cs 等），提升到 Pipeline/ 下加 pipeline_ 前缀：
```
abs_core/Pipeline/Core/IMiddleware.cs        → abs_core/Pipeline/pipeline_IMiddleware.cs
abs_core/Pipeline/Core/IPipelineHook.cs      → abs_core/Pipeline/pipeline_IPipelineHook.cs
... (共8个文件)
```
提升后 abs_core/Pipeline/ 下有 context/hooks/pipeline_*.cs，需检查纯净性（文件夹和文件混排）。
若混排违反纯净性，则 pipeline_*.cs 放入 abs_core/Pipeline/pipeline_core/ 子目录。

### 2.4 abs_ai/LLM/Chat/Core/ 提升

Chat/Core/ 下都是 .cs 文件（ApiMessage.cs 等），提升到 Chat/ 下加 chat_ 前缀：
```
abs_ai/LLM/Chat/Core/ApiMessage.cs    → abs_ai/LLM/Chat/chat_ApiMessage.cs
... (共17个文件)
```
同样检查纯净性，若混排则放入 chat_core/ 子目录。

McpToolJsonContext.cs 保留在 Models/ 根目录或移入 models_system/。

## 四、私人助手 / 共享助手

### 4.1 规则

| 类型 | 位置 | 作用 |
|------|------|------|
| private/ | 每个工具内部 | 工具私人助手，仅该工具可见，降低对外暴露疑惑 |
| shared/ | 本层所有工具共享 | 本层共享助手，同层工具可复用 |

### 4.2 示例

```
03_builtin/
├── src/
│   ├── tool_handlers/
│   │   ├── handlers/
│   │   └── private/          # tool_handlers 私人助手
│   └── shared/               # 03_builtin 层共享助手
├── tests/
└── Directory.Build.props
```

### 4.3 范围

每个有内部子模块的功能项目都加 private/shared：
- 03_builtin/src/tool_handlers/private/
- 03_builtin/src/shared/
- 05_server_bridge/src/shared/
- 04_mcp_service/src/shared/
- 等等

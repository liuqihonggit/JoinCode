# 提示词工具名绑定重构

## 目标

把提示词正文里的硬编码工具名（裸字符串）改成 `XxxToolNameConstants` 常量引用，实现：
- **改一处自动同步**：改枚举 `[EnumValue]` → 源码生成器重新生成常量 → `[McpTool]` 注册 + 提示词正文全部自动更新
- **编译时验证**：删枚举成员 → 常量消失 → 引用处编译失败
- **修正错误名**：`FileReadTool`→`Read`、`GlobTool`→`Glob` 等（LLM 照错误名调用会失败）

## 方案

用现有 `XxxToolNameConstants`（枚举 + `[EnumValue]` + `EnumMetadata.Generator` 生成）。
不新建 `RegisteredToolNames` 生成器（per-assembly 约束：跨程序集不可行）。

# TASK139 — NativeTui 输入热路径分配优化

## 目标

在不改变输入解析、粘贴、超时与终端响应语义的前提下，消除两项已定位的重复工作：

1. `RawStdinPump` 大粘贴分块时反复复制、扫描和前移整个 pending 缓冲。
2. `TerminalResponseParser` 对普通非回复 CSI 提前收集数字并构造原始字符串。

## 真机验收追加缺陷

普通 CSI 的参数/intermediate 扫描在遇到非法控制字节时，原实现仍把该字节当作 final 消费。若该字节是下一个 `ESC`，恢复序列会被切成普通 `[`、`A` 字符。新增 3 个 ECMA-48 final 字节范围回归，修复为仅消费合法 final（0x40-0x7E），控制字节保留给下一轮解析。

# 任务：改进 GUI 命令补全（w3 rebase 引入）

## 背景

用户反馈：w3 分支做了非常难看的命令补全，需要修改好。
已执行 `git rebase w3` 将提交 `bce2a3ea7`（命令类从 CLI 迁移到 Composition + GUI 命令面板从源码生成器获取 80+ 命令）引入 w4。

## 现状问题分析

| 问题 | 位置 |
|------|------|
| 独立 Window 弹窗，非内联下拉补全 | `CommandPalette.cs` 继承 `Window` |
| 一次性过滤：打开时传固定前缀 `/`，80+ 命令全部展示，无法继续输入过滤 | `MainWindow.axaml.cs:433` |
| 触发条件苛刻：要求输入框为空才弹出，输入 `/c` 不实时补全 | `MainWindow.axaml.cs:329` |
| 样式硬编码 `#4da6ff`/`#979797`，不随深浅主题 | `CommandPalette.cs:50,56` |
| 不显示 Usage 用法提示 | `CommandPalette.cs` 模板只有 Name+Description |

## 决策（已确认）

- **内联 Popup 实时补全**：输入框输入 `/` 后立即出现内联下拉，继续输入实时过滤，↑↓ 选择 Enter 补全，Esc 关闭。
- **样式接 GuiPalette 主题资源**：下拉背景/边框/文字全部用 DynamicResource，随深浅主题切换。

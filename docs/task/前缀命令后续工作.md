# 前缀命令后续工作

> ADR: [0066](../adr/0066-prefix-exclamation-command.md)
> 基础实现已完成（commit 39f80526c），本文档记录后续完善任务。

## 任务清单

### 任务1：补充跨平台支持 ✅
- **现状**：`ShellExecutor` 硬编码 `cmd.exe`，`SilentShellPrefixCommandHandler` 硬编码 `explorer.exe`，仅支持 Windows
- **目标**：
  - `ShellExecutor`：Windows 用 `cmd /c`，Linux/macOS 用 `bash -c`
  - `SilentShellPrefixCommandHandler.TryHandleDirectory`：Windows 用 `explorer.exe`，Linux 用 `xdg-open`，macOS 用 `open`
  - `OpenWithDefaultProgram`：跨平台 `UseShellExecute=true` 已支持，无需改
- **验证**：单元测试补充跨平台分支（用 `OperatingSystem.IsWindows()` 等条件跳过）

### 任务2：启用底部状态栏提示 ✅
- **现状**：`FooterBashModeHint`（`! bash mode`）本地化字符串已定义但从未消费，CLI 无底部状态栏渲染
- **目标**：
  - 新增 `FooterSilentBashModeHint`（`!! silent` / `!! 静默`）本地化字符串
  - 在 `ReplLoopStep` 主循环渲染底部提示行：`! bash mode | !! silent | ? for shortcuts`
  - 仅在交互模式（非 headless）渲染，避免污染管道输出
- **验证**：编译通过，交互模式可见底部提示

### 任务3：E2E 验证 ✅
- **结果**：
  - `!!echo hello` → 静默执行，输出 `$ echo hello` + `hello`，不触发 AI ✅
  - `!dir` → 执行 dir，输出注入 AI 上下文，触发 StreamResponseAsync（API 超时是网络问题，路由正确）✅
  - dir 输出正确捕获（`Volume in drive D` / `Directory of D:\project\w4`）✅
- **死锁修复**：E2E 暴露 CodeIndex TreeCache 锁嵌套死锁 + LockRegistry 误报，已修复（commit 80b665caf）

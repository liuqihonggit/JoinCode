jcc-tool-analytics — analytics 工具分组（12 个工具）

用法:
  jcc-tool-analytics.exe <工具名> [参数...]
  jcc-tool-analytics.exe -h
  jcc-tool-analytics.exe <工具名> -h

工具列表（说明复用自 [McpTool] 特性）:
  analytics_report                   Get system usage statistics report
  analytics_tools                    Get tool usage statistics details
  analytics_events                   Get analytics event history
  analytics_export                   Export analytics data as JSON
  analytics_clear                    Clear analytics history data
  agent_system_stats                 Get overall agent execution statistics
  agent_list_stats                   List statistics for all agents
  agent_stats                        Get detailed statistics for a specific agent
  agent_history                      Get execution history for an agent
  agent_running_stats                Get currently running agent executions
  agent_execution_detail             Get detailed information about a specific execution
  agent_clear_history                Clear agent execution history

单个工具的参数说明:

  analytics_report — Get system usage statistics report
    --days                       integer   可选   Number of days for statistics (default 7)

  analytics_tools — Get tool usage statistics details
    --days                       integer   可选   Number of days for statistics (default 7)

  analytics_events — Get analytics event history
    --event_type                 string    可选   Event type filter (optional)
    --limit                      integer   可选   Result count limit

  analytics_export — Export analytics data as JSON
    --start_date                 string    可选   Start date (optional)
    --end_date                   string    可选   End date (optional)

  analytics_clear — Clear analytics history data
    --older_than_days            integer   可选   Clear data older than N days (optional)
    --confirm                    string    必填   Confirm clear (enter 'yes' to confirm)

  agent_system_stats — Get overall agent execution statistics
    (无参数)

  agent_list_stats — List statistics for all agents
    (无参数)

  agent_stats — Get detailed statistics for a specific agent
    --agent_name                 string    必填   Agent name

  agent_history — Get execution history for an agent
    --agent_name                 string    必填   Agent name
    --limit                      integer   可选   Result count limit

  agent_running_stats — Get currently running agent executions
    (无参数)

  agent_execution_detail — Get detailed information about a specific execution
    --execution_id               string    必填   Execution ID

  agent_clear_history — Clear agent execution history
    --older_than_days            integer   可选   Clear records older than N days (optional)
    --confirm                    string    必填   Confirm clear (enter 'yes' to confirm)

描述来源: 现有 [McpTool] / [McpToolParameter] 特性，由本脚本在编译期提取。

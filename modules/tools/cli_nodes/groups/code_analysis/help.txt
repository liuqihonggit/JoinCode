jcc-tool-code_analysis — code_analysis 工具分组（4 个工具）

用法:
  jcc-tool-code_analysis.exe <工具名> [参数...]
  jcc-tool-code_analysis.exe -h
  jcc-tool-code_analysis.exe <工具名> -h

工具列表（说明复用自 [McpTool] 特性）:
  analyze_csharp_code                Analyze C# code quality and provide improvement suggestions
  find_bugs                          Find potential bugs and issues in C# code
  optimize_code                      Analyze and optimize C# code performance and readability
  security_audit                     Perform security audit on C# code

单个工具的参数说明:

  analyze_csharp_code — Analyze C# code quality and provide improvement suggestions
    --code                       string    必填   C# code to analyze
    --focus                      string    可选   Analysis focus: quality, performance, security, maintainability, all  默认=all

  find_bugs — Find potential bugs and issues in C# code
    --code                       string    必填   C# code to check
    --severity                   string    可选   Bug severity filter: low, medium, high, critical, all  默认=all

  optimize_code — Analyze and optimize C# code performance and readability
    --code                       string    必填   C# code to optimize
    --target                     string    可选   Optimization target: performance, memory, readability, all  默认=all

  security_audit — Perform security audit on C# code
    --code                       string    必填   C# code to audit
    --audit_type                 string    可选   Audit type: web, api, desktop, general  默认=general

描述来源: 现有 [McpTool] / [McpToolParameter] 特性，由本脚本在编译期提取。

jcc-tool-cron — cron 工具分组（4 个工具）

用法:
  jcc-tool-cron.exe <工具名> [参数...]
  jcc-tool-cron.exe -h
  jcc-tool-cron.exe <工具名> -h

工具列表（说明复用自 [McpTool] 特性）:
  cron_create                        Create a scheduled task that runs at specified intervals using cron syntax
  cron_list                          List all scheduled tasks
  cron_delete                        Delete a scheduled task by ID
  cron_validate                      Validate a cron expression and show its parsed fields

单个工具的参数说明:

  cron_create — Create a scheduled task that runs at specified intervals using cron syntax
    --cron                       string    必填   Cron expression (5 fields: minute hour day month weekday, e.g. "0 9 * * *" for daily at 9am)
    --prompt                     string    必填   The prompt/instruction to execute when the task fires
    --recurring                  boolean   可选   Whether this is a recurring task (default: true). Set to false for one-shot tasks.  默认=true
    --durable                    boolean   可选   Whether to persist the task to disk (default: false). Session-only tasks are lost when the session ends.  默认=false

  cron_list — List all scheduled tasks
    (无参数)

  cron_delete — Delete a scheduled task by ID
    --task_id                    string    必填   The ID of the scheduled task to delete

  cron_validate — Validate a cron expression and show its parsed fields
    --cron                       string    必填   Cron expression to validate

描述来源: 现有 [McpTool] / [McpToolParameter] 特性，由本脚本在编译期提取。

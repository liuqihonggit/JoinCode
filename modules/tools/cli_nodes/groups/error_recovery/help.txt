jcc-tool-error_recovery — error_recovery 工具分组（7 个工具）

用法:
  jcc-tool-error_recovery.exe <工具名> [参数...]
  jcc-tool-error_recovery.exe -h
  jcc-tool-error_recovery.exe <工具名> -h

工具列表（说明复用自 [McpTool] 特性）:
  diagnose_error                     分析工具执行失败的错误信息，提供诊断和修复建议
  fix_shell_error                    分析 Shell 命令执行失败原因，提供替代命令建议
  fix_file_error                     分析文件操作失败原因，提供修复路径建议
  fix_merge_conflict                 分析 worktree 合并失败原因，检测遗留冲突标记和分支冲突，提供修复建议
  resume_timed_out_task              恢复因超时被终止的命令，以更长超时重新执行
  continue_long_running_task         继续等待长时间运行的任务，以指定超时再次执行
  stop_long_running_task             终止长时间运行的任务

单个工具的参数说明:

  diagnose_error — 分析工具执行失败的错误信息，提供诊断和修复建议
    --errorMessage               string    必填   失败的错误信息
    --failedToolName             string    必填   失败的工具名称
    --workingDirectory           string    可选   工作目录路径

  fix_shell_error — 分析 Shell 命令执行失败原因，提供替代命令建议
    --failedCommand              string    必填   失败的命令
    --errorOutput                string    必填   错误输出
    --exitCode                   integer   可选   退出码

  fix_file_error — 分析文件操作失败原因，提供修复路径建议
    --filePath                   string    必填   失败的文件路径
    --errorMessage               string    必填   错误信息

  fix_merge_conflict — 分析 worktree 合并失败原因，检测遗留冲突标记和分支冲突，提供修复建议
    --source_worktree_path       string    必填   源 worktree 路径
    --target_worktree_path       string    必填   目标 worktree 路径
    --error_message              string    必填   错误信息

  resume_timed_out_task — 恢复因超时被终止的命令，以更长超时重新执行
    --original_command           string    必填   原始命令
    --original_tool              string    必填   原始工具名称 (Bash/PowerShell)
    --timeout_minutes            integer   可选   续期超时分钟数 (默认10)  默认=10
    --working_directory          string    可选   工作目录

  continue_long_running_task — 继续等待长时间运行的任务，以指定超时再次执行
    --task_id                    string    必填   任务ID
    --additional_minutes         integer   可选   额外等待分钟数 (默认10)  默认=10

  stop_long_running_task — 终止长时间运行的任务
    --task_id                    string    必填   任务ID

描述来源: 现有 [McpTool] / [McpToolParameter] 特性，由本脚本在编译期提取。

单个工具的参数说明:

  gh_api — 通用 GitHub REST API 调用(直调 api.github.com,输出完整 JSON)
    --path                       string    必填   API 路径(如 repos/owner/repo/issues)
    --method                     string    可选   HTTP 方法(GET/POST/PATCH/PUT/DELETE,默认 GET,path 为 graphql 时默认 POST)
    --body                       string    可选   请求体 JSON(可选,POST/PATCH/PUT 用)
    --body_file                  string    可选   请求体 JSON 文件路径(可选,读取文件内容作为 body,彻底绕开命令行转义问题)
    --fields                     string    可选   查询参数(可选,格式 key=value,多个用逗号分隔)
    --jq                         string    可选   jq 表达式(可选,筛选结果。支持 .field/.field.sub/[]/select(.f=="v" or .g=="w")/{k: .f}/| 管道)
    --paginate                   boolean   可选   是否分页(默认 false,结果多时启用)
    --max_lines                  integer   可选   最大输出行数(默认 500,超出截断)
    --working_dir                string    可选   工作目录(可选,REST API 直调时忽略,保留兼容性)

  gh_auth_status — 查看 GitHub Auth 状态
    (无参数)

  gh_auth_login — 登录 GitHub(PAT token 验证后保存到 hosts.yml)
    --token                      string    必填   GitHub PAT token(ghp_xxx)
    --host                       string    可选   host(可选,默认 github.com)

  gh_auth_token — 获取 GitHub Auth token(从 hosts.yml 读取)
    --host                       string    可选   host(可选,默认 github.com)

  gh_auth_refresh — 刷新 GitHub Auth token(提示用系统 gh)
    --host                       string    可选   host(可选,默认 github.com)

  gh_auth_setup_git — 配置 git credential helper 使用 gh
    --host                       string    可选   host(可选,默认 github.com)

  gh_config_list — 列出 gh 配置(读写 config.yml)
    --host                       string    可选   host(可选,列出 per-host 设置,读写 hosts.yml)

  gh_config_get — 读取 gh 配置(读写 config.yml)

jcc-tool-goal — goal 工具分组（3 个工具）

用法:
  jcc-tool-goal.exe <工具名> [参数...]
  jcc-tool-goal.exe -h
  jcc-tool-goal.exe <工具名> -h

工具列表（说明复用自 [McpTool] 特性）:
  goal_get                           Get the current goal status including objective, progress, and evaluation results. Returns null if no goal is active.
  goal_update                        Update the current goal status. The model can mark a goal as achieved or unmet. Only 'achieved' and 'unmet' statuses are allowed via this tool.
  goal_graph_define                  Define a goal execution graph with nodes and edges. The coordinator agent uses this after investigating the task to create an optimal execution plan. Each node is an agent loop, edges define execution flow and conditional routing.

单个工具的参数说明:

  goal_get — Get the current goal status including objective, progress, and evaluation results. Returns null if no goal is active.
    (无参数)

  goal_update — Update the current goal status. The model can mark a goal as achieved or unmet. Only 'achieved' and 'unmet' statuses are allowed via this tool.
    --reason                     string    必填   Reason for the status change

  goal_graph_define — Define a goal execution graph with nodes and edges. The coordinator agent uses this after investigating the task to create an optimal execution plan. Each node is an agent loop, edges define execution flow and conditional routing.
    --nodes                      string    必填   JSON array of nodes. Each node: {id, kind, name, systemPrompt?, instruction?, freshContext?}. kind: agent/function/join
    --edges                      string    必填   JSON array of edges. Each edge: {id?, fromId, toId, label?}. Empty label = unconditional, non-empty = conditional route key
    --start_node_id              string    必填   Start node ID
    --end_node_ids               string    必填   End node IDs, comma-separated

描述来源: 现有 [McpTool] / [McpToolParameter] 特性，由本脚本在编译期提取。

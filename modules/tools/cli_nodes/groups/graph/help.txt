jcc-tool-graph — graph 工具分组（16 个工具）

用法:
  jcc-tool-graph.exe <工具名> [参数...]
  jcc-tool-graph.exe -h
  jcc-tool-graph.exe <工具名> -h

工具列表（说明复用自 [McpTool] 特性）:
  graph_detect_communities           Detect code communities (modules/subsystems) using label propagation algorithm on the call graph
  graph_get_hub_nodes                Find hub nodes with highest connectivity (in-degree + out-degree) in the call graph
  graph_detect_dead_code             Detect potentially dead code: methods with no callers that are not entry points
  graph_extract_subgraph             Extract a subgraph centered on a symbol with N hops radius
  graph_analyze_change_impact        Analyze the blast radius of changes to specified files
  graph_save                         Save the code index to disk for fast reload on next startup
  graph_load                         Load a previously saved code index from disk
  graph_export_dot                   Export the call graph as DOT format for Graphviz visualization
  graph_export_html                  Export the call graph as interactive HTML with D3.js force-directed layout
  graph_export_wiki                  Export code architecture as Markdown wiki based on community structure
  graph_query                        Query the code graph with natural language to find related symbols and subgraph summaries
  graph_path                         Find the shortest path between two symbols in the call graph
  graph_explain                      Explain a symbol's role and relationships in the codebase (callers, callees, community, same-file)
  graph_register                     Register a repository for multi-repo graph analysis
  graph_unregister                   Unregister a repository from multi-repo graph analysis
  graph_repos                        List all registered repositories for multi-repo graph analysis

单个工具的参数说明:

  graph_detect_communities — Detect code communities (modules/subsystems) using label propagation algorithm on the call graph
    --repo_id                    string    必填   Repository ID (default: default)

  graph_get_hub_nodes — Find hub nodes with highest connectivity (in-degree + out-degree) in the call graph
    --top_n                      integer   必填   Number of top hub nodes to return (default 10)  默认=10
    --repo_id                    string    必填   Repository ID (default: default)

  graph_detect_dead_code — Detect potentially dead code: methods with no callers that are not entry points
    --repo_id                    string    必填   Repository ID (default: default)

  graph_extract_subgraph — Extract a subgraph centered on a symbol with N hops radius
    --center_symbol              string    必填   Center symbol name
    --hops                       integer   必填   Number of hops (radius, default 2)  默认=2
    --max_edges                  integer   必填   Maximum edges to return (default 50, pass larger to see more)  默认=50
    --repo_id                    string    必填   Repository ID (default: default)

  graph_analyze_change_impact — Analyze the blast radius of changes to specified files
    --changed_files              string    必填   Comma-separated list of changed file paths
    --repo_id                    string    必填   Repository ID (default: default)

  graph_save — Save the code index to disk for fast reload on next startup
    --directory                  string    必填   Directory path to save the index (default: .jcc/graph)  默认=.jcc/graph
    --repo_id                    string    必填   Repository ID (default: default)

  graph_load — Load a previously saved code index from disk
    --directory                  string    必填   Directory path to load the index from (default: .jcc/graph)  默认=.jcc/graph
    --repo_id                    string    必填   Repository ID (default: default)

  graph_export_dot — Export the call graph as DOT format for Graphviz visualization
    --repo_id                    string    必填   Repository ID (default: default)

  graph_export_html — Export the call graph as interactive HTML with D3.js force-directed layout
    --repo_id                    string    必填   Repository ID (default: default)

  graph_export_wiki — Export code architecture as Markdown wiki based on community structure
    --repo_id                    string    必填   Repository ID (default: default)

  graph_query — Query the code graph with natural language to find related symbols and subgraph summaries
    --query                      string    必填   Natural language query (e.g. 'how does auth work')
    --max_results                integer   必填   Maximum number of results (default 20)  默认=20
    --repo_id                    string    必填   Repository ID (default: default)

  graph_path — Find the shortest path between two symbols in the call graph
    --from_symbol                string    必填   Starting symbol name
    --to_symbol                  string    必填   Target symbol name
    --repo_id                    string    必填   Repository ID (default: default)

  graph_explain — Explain a symbol's role and relationships in the codebase (callers, callees, community, same-file)
    --symbol_name                string    必填   Symbol name to explain
    --limit                      integer   必填   Maximum items per category (default 5, pass larger to see more)  默认=5
    --repo_id                    string    必填   Repository ID (default: default)

  graph_register — Register a repository for multi-repo graph analysis
    --repo_id                    string    必填   Repository identifier (e.g. 'frontend', 'backend')
    --workspace_root             string    必填   Workspace root path of the repository

  graph_unregister — Unregister a repository from multi-repo graph analysis
    --repo_id                    string    必填   Repository identifier to remove

  graph_repos — List all registered repositories for multi-repo graph analysis
    (无参数)

描述来源: 现有 [McpTool] / [McpToolParameter] 特性，由本脚本在编译期提取。

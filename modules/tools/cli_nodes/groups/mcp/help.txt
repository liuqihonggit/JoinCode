jcc-tool-mcp — mcp 工具分组（25 个工具）

  jcc-tool-mcp.exe <工具名> [参数...]
  jcc-tool-mcp.exe -h
  jcc-tool-mcp.exe <工具名> -h

单个工具的参数说明:

  auth_get_status — Get authentication status for a config or all configs
    --auth_name                  string    可选   Authentication config name (optional, omit for all)

  auth_refresh — Refresh authentication token
    --auth_name                  string    必填   Authentication config name

  auth_logout — Logout and revoke authentication session
    --auth_name                  string    必填   Authentication config name

  mcp_auth_apikey — Configure API key authentication for MCP server
    --auth_name                  string    必填   Authentication config name
    --api_key                    string    必填   API key
    --header_name                string    可选   Header name  默认=X-API-Key

  mcp_auth_bearer — Configure Bearer Token authentication for MCP server
    --auth_name                  string    必填   Authentication config name
    --token                      string    必填   Bearer Token

  mcp_auth_basic — Configure Basic authentication for MCP server
    --auth_name                  string    必填   Authentication config name
    --username                   string    必填   Username
    --password                   string    必填   Password

  mcp_auth_oauth2 — Configure OAuth2 authentication for MCP server
    --auth_name                  string    必填   Authentication config name
    --client_id                  string    必填   Client ID
    --client_secret              string    必填   Client secret
    --token_url                  string    必填   Token URL
    --scopes                     string    可选   Authorization scopes (comma-separated)

  mcp_auth_refresh — Refresh MCP authentication token
    --auth_name                  string    必填   Authentication config name

  mcp_auth_status — Get MCP authentication status
    --auth_name                  string    可选   Authentication config name

  mcp_auth_remove — Delete MCP authentication config
    --auth_name                  string    必填   Authentication config name

  mcp_connect — Connect to MCP server
    --connection_name            string    必填   Connection name for subsequent reference
    --endpoint                   string    必填   Server endpoint (command or URL)
    --transport_type             string    可选   Transport type: stdio, sse, http  默认=McpTransportTypeEnumConstants.Stdio
    --use_oauth                  boolean   可选   Whether to use OAuth authentication  默认=false
    --auth_name                  string    可选   Authentication config name (from mcp_auth_*)

  mcp_disconnect — Disconnect from MCP server
    --connection_name            string    必填   Connection name

  mcp_disable_server — Disable an MCP server (persisted to disk)
    --connection_name            string    必填   Connection name

  mcp_enable_server — Enable an MCP server (persisted to disk)
    --connection_name            string    必填   Connection name

  mcp_list_tools — List tools on MCP server
    --connection_name            string    必填   Connection name

  mcp_call_tool — Call a tool on MCP server
    --connection_name            string    必填   Connection name
    --tool_name                  string    必填   Tool name
    --arguments_json             string    可选   Tool arguments (JSON object)

  list_mcp_resources — List resources on MCP server
    --connection_name            string    必填   Connection name

  read_mcp_resource — Read a resource from MCP server
    --connection_name            string    必填   Connection name
    --resource_uri               string    必填   Resource URI

  mcp_list_prompts — List prompt templates on MCP server
    --connection_name            string    必填   Connection name

  mcp_remote_list_resources — List all available MCP remote resources
    --client_id                  string    可选   Remote client ID (optional, list resources for a specific client)

  mcp_remote_read_resource — Read the content of an MCP remote resource by URI
    --uri                        string    必填   Resource URI
    --client_id                  string    可选   Remote client ID (optional)

  mcp_remote_list_prompts — List all available MCP remote prompt templates
    --client_id                  string    可选   Remote client ID (optional)

  mcp_get_prompt — Get an MCP prompt template by name
    --prompt_name                string    必填   Prompt template name
    --arguments                  string    可选   Arguments (JSON format)
    --client_id                  string    可选   Remote client ID (optional)

  mcp_list_clients — List all connected MCP remote clients
    (无参数)

  monitor — Monitor MCP server status and tool calls
    --monitor_type               string    可选   Monitor type: status/tools/clients/health (default status)  默认=status
    --client_id                  string    可选   Client ID (optional, for specific client)

描述来源: 现有 [McpTool] / [McpToolParameter] 特性，由本脚本在编译期提取。

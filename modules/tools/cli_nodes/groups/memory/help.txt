jcc-tool-memory — memory 工具分组（13 个工具）

用法:
  jcc-tool-memory.exe <工具名> [参数...]
  jcc-tool-memory.exe -h
  jcc-tool-memory.exe <工具名> -h

工具列表（说明复用自 [McpTool] 特性）:
  memory_daily_log_append            Append an entry to the assistant daily log
  memory_daily_log_get               Get today's assistant daily log
  memory_search_history              Search past conversation memories
  memory_team_sync                   Sync team memories
  memory_team_status                 Get team sync status
  memory_scan                        Scan memories to find relevant ones
  memory_age                         Get memory age and access statistics
  memory_cleanup                     Clean up old memories (archive or delete)
  memory_health                      Get memory health report
  memory_add_team_path               Add a team shared memory path
  memory_list_team_paths             List team memory paths
  memory_remove_team_path            Remove a team memory path
  memory_scan_team                   Scan team shared memories

单个工具的参数说明:

  memory_daily_log_append — Append an entry to the assistant daily log
    --content                    string    必填   Log content
    --category                   string    可选   Log category (Action/Observation/Decision/Result, optional)
    --related_memory_id          string    可选   Related memory ID (optional)

  memory_daily_log_get — Get today's assistant daily log
    (无参数)

  memory_search_history — Search past conversation memories
    --query                      string    必填   Search query
    --limit                      integer   可选   Result count limit

  memory_team_sync — Sync team memories
    --team_id                    string    必填   Team ID

  memory_team_status — Get team sync status
    --team_id                    string    必填   Team ID

  memory_scan — Scan memories to find relevant ones
    --query                      string    必填   Search query
    --category                   string    可选   Category filter (optional)
    --limit                      integer   可选   Result count limit

  memory_age — Get memory age and access statistics
    --attention_only             boolean   可选   Show only memories needing attention

  memory_cleanup — Clean up old memories (archive or delete)
    --archive_after_days         integer   可选   Archive threshold in days (default 90)
    --delete_after_days          integer   可选   Delete threshold in days (default 180)
    --confirm                    string    必填   Confirm execution (enter 'yes' to confirm)

  memory_health — Get memory health report
    (无参数)

  memory_add_team_path — Add a team shared memory path
    --team_id                    string    必填   Team ID
    --path                       string    必填   Memory path
    --is_shared                  boolean   可选   Whether shared
    --allowed_agents             string    可选   Allowed agents list (comma-separated)

  memory_list_team_paths — List team memory paths
    --team_id                    string    可选   Team ID (optional, omit to show all)

  memory_remove_team_path — Remove a team memory path
    --team_id                    string    必填   Team ID
    --path                       string    必填   Memory path

  memory_scan_team — Scan team shared memories
    --team_id                    string    必填   Team ID
    --query                      string    必填   Search query
    --limit                      integer   可选   Result count limit

描述来源: 现有 [McpTool] / [McpToolParameter] 特性，由本脚本在编译期提取。

jcc-tool-notebook — notebook 工具分组（13 个工具）

用法:
  jcc-tool-notebook.exe <工具名> [参数...]
  jcc-tool-notebook.exe -h
  jcc-tool-notebook.exe <工具名> -h

工具列表（说明复用自 [McpTool] 特性）:
  notebook_add_cell                  Add a cell to a notebook
  notebook_delete_cell               Delete a cell from a notebook
  notebook_edit_cell                 Edit a notebook cell's content
  notebook_move_cell                 Move a notebook cell to a new position
  notebook_change_cell_type          Change a notebook cell's type
  notebook_clear_outputs             Clear outputs of all notebook cells
  notebook_get_cell                  Get the content of a specific notebook cell
  notebook_edit                      Replace the contents of a specific cell in a Jupyter notebook (.ipynb)
  notebook_create                    Create a new Jupyter Notebook file
  notebook_read                      Read a Jupyter Notebook file
  recall_list                        List folded conversation archives that can be recalled
  recall_read                        Read full original content of a folded archive by fold_id
  recall_search                      Search folded archives by keyword in summary text

单个工具的参数说明:

  notebook_add_cell — Add a cell to a notebook
    --file_path                  string    必填   File path
    --cell_type                  string    必填   Cell type (code/markdown/raw)
    --content                    string    必填   Cell content
    --index                      integer   可选   Insert position index (optional, default end)

  notebook_delete_cell — Delete a cell from a notebook
    --file_path                  string    必填   File path
    --index                      integer   必填   Cell index

  notebook_edit_cell — Edit a notebook cell's content
    --file_path                  string    必填   File path
    --index                      integer   必填   Cell index
    --content                    string    必填   New content

  notebook_move_cell — Move a notebook cell to a new position
    --file_path                  string    必填   File path
    --from_index                 integer   必填   Source position index
    --to_index                   integer   必填   Target position index

  notebook_change_cell_type — Change a notebook cell's type
    --file_path                  string    必填   File path
    --index                      integer   必填   Cell index
    --new_type                   string    必填   New type (code/markdown/raw)

  notebook_clear_outputs — Clear outputs of all notebook cells
    --file_path                  string    必填   File path

  notebook_get_cell — Get the content of a specific notebook cell
    --file_path                  string    必填   File path
    --index                      integer   必填   Cell index

  notebook_edit — Replace the contents of a specific cell in a Jupyter notebook (.ipynb)
    --notebook_path              string    必填   The absolute path to the Jupyter notebook file to edit
    --new_source                 string    必填   The new source for the cell
    --cell_id                    string    可选   The ID of the cell to edit (optional for insert mode)
    --cell_type                  string    可选   The type of the cell: code or markdown (required for insert)
    --edit_mode                  string    可选   The type of edit: replace, insert, or delete (default: replace)

  notebook_create — Create a new Jupyter Notebook file
    --file_path                  string    必填   File path
    --kernel_name                string    可选   Kernel name (e.g. python3)
    --language                   string    可选   Programming language (e.g. python)

  notebook_read — Read a Jupyter Notebook file
    --file_path                  string    必填   File path
    --show_content               boolean   可选   Whether to show cell contents

  recall_list — List folded conversation archives that can be recalled
    (无参数)

  recall_read — Read full original content of a folded archive by fold_id
    --fold_id                    string    必填   The fold_id of the archive to read (from recall_list)

  recall_search — Search folded archives by keyword in summary text
    --keyword                    string    必填   Keyword to search in archive summaries

描述来源: 现有 [McpTool] / [McpToolParameter] 特性，由本脚本在编译期提取。

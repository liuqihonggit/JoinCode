jcc-tool-shell — shell 工具分组（27 个工具）

用法:
  jcc-tool-shell.exe <工具名> [参数...]
  jcc-tool-shell.exe -h
  jcc-tool-shell.exe <工具名> -h

工具列表（说明复用自 [McpTool] 特性）:
  execute_csharp_code                Execute C# code in sandbox environment
  evaluate_expression                Evaluate a simple C# expression
  test_code_snippet                  Test a code snippet with sample input
  build_output                       Get build output lines by range for incremental reading
  build_queue_status                 Get build queue status (pending count, current build, recent builds)
  build_cancel                       Cancel a build (kill process if building, remove from queue if pending)
  powershell                         Execute a PowerShell command. The description parameter briefly describes the command purpose
  powershell_script                  Execute PowerShell script file (.ps1)
  powershell_version                 Get PowerShell version and runtime information
  powershell_execution_policy        Get current PowerShell execution policy
  powershell_set_execution_policy    Set PowerShell execution policy (requires administrator privileges)
  bash                               Execute a Bash/CMD command. The description parameter briefly describes the command purpose
  shell_background_get               Get background shell task status
  shell_background_list              List all background shell tasks
  shell_background_output            Get output of a background shell task
  shell_background_cancel            Cancel a background shell task
  shell_background_kill_all          Force kill ALL running background shell tasks and reclaim memory
  mcp_ai_workflow_workflow_execute   Execute workflow tasks for running and starting various automated workflows
  mcp_ai_workflow_plan_create_and_execute Create and execute plans for complex task planning
  repl                               Execute code in REPL interactive mode
  terminal_capture                   Capture terminal screen content snapshot
  sandbox_enter                      Enter a sandbox with the specified isolation type. If the requested type is unavailable, automatically falls back to a lower isolation level. Available types: soft (path redirection), process (OS-level process isolation), docker (container isolation), bubblewrap (Linux namespace isolation).
  sandbox_exit                       Exit the current sandbox and restore normal access.
  sandbox_switch                     Switch to a different sandbox type while preserving isolation settings. Useful for escalating or de-escalating isolation level. If the target type is unavailable, automatically falls back.
  sandbox_status                     Get the current sandbox status including type, isolation level, available types, and health state.
  sandbox_exec                       Execute a command inside the sandbox with anti-stuck timeout protection. When timeout is reached, the command is NOT interrupted - instead you (LLM) are asked to decide: continue waiting or force stop. Default timeout is 2 minutes.
  sandbox_exec_continue              Continue a timed-out sandbox execution. Choose to wait longer or force stop the command.

单个工具的参数说明:

  execute_csharp_code — Execute C# code in sandbox environment
    --code                       string    必填   C# code to execute
    --timeout_ms                 integer   可选   Execution timeout in milliseconds, defaults to 30000  默认=30000
    --allow_external_libs        boolean   可选   Allow external libraries  默认=false

  evaluate_expression — Evaluate a simple C# expression
    --expression                 string    必填   C# expression to evaluate, e.g. '1 + 2 * 3' or 'DateTime.Now.ToString()'
    --variables                  string    可选   Variable definitions in JSON format (optional)

  test_code_snippet — Test a code snippet with sample input
    --code                       string    必填   C# code snippet to test
    --test_input                 string    必填   Sample input in JSON format
    --expected_output            string    可选   Expected output (optional)

  build_output — Get build output lines by range for incremental reading
    --build_id                   string    必填   Build ID (e.g. b-0001)
    --start_line                 integer   必填   Start line number (1-based)
    --end_line                   integer   可选   End line number (inclusive, 0=to end)

  build_queue_status — Get build queue status (pending count, current build, recent builds)
    (无参数)

  build_cancel — Cancel a build (kill process if building, remove from queue if pending)
    --build_id                   string    必填   Build ID (e.g. b-0001)

  powershell — Execute a PowerShell command. The description parameter briefly describes the command purpose
    --command                    string    必填   PowerShell command to execute
    --description                string    可选   Brief description of the command purpose
    --timeout                    integer   可选   Timeout in milliseconds, default 180000ms (3 minutes)
    --working_directory          string    可选   Working directory, defaults to current directory
    --run_in_background          boolean   可选   Run in background (do not wait for completion)
    --auto_background            boolean   可选   Enable auto-backgrounding on timeout
    --dangerously_disable_sandbox boolean   可选   Override sandbox mode for this command

  powershell_script — Execute PowerShell script file (.ps1)
    --script_path                string    必填   Script file path
    --arguments                  string    可选   Script arguments (optional)
    --no_profile                 boolean   可选   Do not load PowerShell profile
    --execution_policy           string    可选   Execution policy
    --timeout                    integer   可选   Timeout in milliseconds
    --working_directory          string    可选   Working directory

  powershell_version — Get PowerShell version and runtime information
    (无参数)

  powershell_execution_policy — Get current PowerShell execution policy
    --scope                      string    可选   Scope (e.g. Process, CurrentUser, LocalMachine)

  powershell_set_execution_policy — Set PowerShell execution policy (requires administrator privileges)
    --policy                     string    必填   Execution policy (e.g. RemoteSigned, Bypass, AllSigned)
    --scope                      string    可选   Scope
    --force                      boolean   可选   Force setting without confirmation prompt

  bash — Execute a Bash/CMD command. The description parameter briefly describes the command purpose
    --command                    string    必填   CMD command to execute. IMPORTANT: For search commands (rg/grep/find/ag), NEVER use --no-ignore/-u flags (bypasses .gitignore, may hang). NEVER search system root paths (C:\, /, /home, C:\Users). Always specify a project subdirectory as the search path.
    --description                string    可选   Brief description of the command purpose
    --timeout                    integer   可选   Timeout in milliseconds, default 180000ms (3 minutes)
    --working_directory          string    可选   Working directory, defaults to current directory
    --run_in_background          boolean   可选   Run in background (do not wait for completion)
    --auto_background            boolean   可选   Enable auto-backgrounding on timeout
    --dangerously_disable_sandbox boolean   可选   Override sandbox mode for this command
    --confirmed_command          string    可选   Confirmed command for MTP anti-char-loss two-round confirmation (second round only)
    --argv_hash                  string    可选   Argv hash for MTP anti-char-loss confirmation (second round, format: #xxxxxx)

  shell_background_get — Get background shell task status
    --task_id                    string    必填   Task ID

  shell_background_list — List all background shell tasks
    (无参数)

  shell_background_output — Get output of a background shell task
    --task_id                    string    必填   Task ID

  shell_background_cancel — Cancel a background shell task
    --task_id                    string    必填   Task ID

  shell_background_kill_all — Force kill ALL running background shell tasks and reclaim memory
    (无参数)

  mcp_ai_workflow_workflow_execute — Execute workflow tasks for running and starting various automated workflows
    --task                       string    必填   Workflow task description, e.g.: Analyze code performance issues and provide optimization suggestions

  mcp_ai_workflow_plan_create_and_execute — Create and execute plans for complex task planning
    --prompt                     string    必填   User task description, AI will create and execute a plan based on this, e.g.: Create a REST API project structure

  repl — Execute code in REPL interactive mode
    --language                   string    可选   REPL language: csharp/powershell/python (default: csharp)  默认=csharp
    --code                       string    可选   Code to execute (optional, shows REPL status if not provided)
    --timeout_seconds            integer   可选   Timeout in seconds (optional, default: 30)  默认=30
    --action                     string    可选   Action: execute/enable/disable/status (default: execute)  默认=execute

  terminal_capture — Capture terminal screen content snapshot
    --capture_type               string    可选   Capture type: screen/buffer (default: screen)  默认=screen
    --max_lines                  integer   可选   Max lines (optional, default: 50)  默认=50

  sandbox_enter — Enter a sandbox with the specified isolation type. If the requested type is unavailable, automatically falls back to a lower isolation level. Available types: soft (path redirection), process (OS-level process isolation), docker (container isolation), bubblewrap (Linux namespace isolation).
    --sandboxType                string    必填   Sandbox type: soft, process, docker, or bubblewrap
    --restrictFileSystem         string    可选   Restrict file system access
    --restrictNetwork            string    可选   Restrict network access
    --sandboxRoot                string    可选   Custom sandbox root path
    --memoryLimitMb              string    可选   Memory limit in MB (process/docker only)
    --cpuLimitPercent            string    可选   CPU limit percent 1-100 (process/docker only)
    --allowFallback              string    可选   Allow automatic fallback to lower isolation if requested type unavailable

  sandbox_exit — Exit the current sandbox and restore normal access.
    (无参数)

  sandbox_switch — Switch to a different sandbox type while preserving isolation settings. Useful for escalating or de-escalating isolation level. If the target type is unavailable, automatically falls back.
    --sandboxType                string    必填   Target sandbox type: soft, process, docker, or bubblewrap

  sandbox_status — Get the current sandbox status including type, isolation level, available types, and health state.
    (无参数)

  sandbox_exec — Execute a command inside the sandbox with anti-stuck timeout protection. When timeout is reached, the command is NOT interrupted - instead you (LLM) are asked to decide: continue waiting or force stop. Default timeout is 2 minutes.
    --command                    string    必填   Command to execute in the sandbox
    --timeout                    string    可选   Timeout preset: 2min (default), 4min, 8min, or custom
    --customTimeoutSeconds       string    可选   Custom timeout in seconds (only used when timeout=custom)

  sandbox_exec_continue — Continue a timed-out sandbox execution. Choose to wait longer or force stop the command.
    --executionId                string    必填   Execution ID from sandbox_exec timeout response
    --action                     string    必填   Action: wait (continue waiting for another timeout period) or stop (force kill the process)

描述来源: 现有 [McpTool] / [McpToolParameter] 特性，由本脚本在编译期提取。

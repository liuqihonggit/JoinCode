单个命令的参数说明:

  /advisor — 配置顾问模型
    用法: /advisor [model|off]
    --model                    string    可选   顾问模型名称,或 off 关闭顾问模式  取值: off

  /agents — 查看和管理代理
    用法: /agents [list|info <name>|resume-all]
    --action                   string    可选   操作: list=列出代理, info=查看详情, resume-all=从历史恢复所有被中断的子代理  取值: list/info/resume-all  默认=list
    --name                     string    可选   代理名称,仅在 action=info 时使用

  /assistant — 长期助手模式
    用法: /assistant [on|off|status]
    --action                   string    可选   助手模式动作  取值: on/off/status  默认=status

  /buddy — 查看你的伙伴精灵
    用法: /buddy
    (无结构化参数)

  /generate — 生成代码
    用法: /generate <描述>
    --description              string    必填   要生成的代码描述

  /memory — 编辑记忆文件
    用法: /memory [edit|open|add|search|db|stats|health|cleanup]
    别名: /mem
    --action                   string    可选   记忆操作  取值: edit/open/add/search/db/stats/health/cleanup

  /plan — 计划模式管理
    用法: /plan [on|off|status|open] [描述]
    --action                   string    可选   计划操作  取值: on/off/status/open
    --description              string    可选   计划描述（on/open 时可选）

  /switch — 切换查看指定子代理输出
    用法: /switch [agentName|all]
    --target                   string    可选   切换目标: agentName=只看指定子代理输出, all=切回显示全部, 省略=显示当前模式

  /ultraplan — 超级计划模式：深度规划+执行
    用法: /ultraplan [goal] [--steps N] [--execute]
    别名: /up
    --goal                     string    可选   规划目标描述
    --steps                    number    可选   规划步骤数
    --execute                  boolean   可选   是否自动执行计划  默认=false

  /login — 登录到 AI 服务
    用法: /login [provider] [--oauth]
    --provider                 string    可选   AI 服务供应商名称
    --oauth                    boolean   可选   使用 OAuth 登录而非 API Key  默认=false

  /logout — 登出 AI 服务
    用法: /logout [provider]
    --provider                 string    可选   要登出的供应商名称,省略则登出当前

  /oauth-refresh — 刷新 OAuth Token
    用法: /oauth-refresh [provider]
    --provider                 string    可选   要刷新 Token 的供应商名称

  /privacy-settings — 管理隐私设置
    用法: /privacy-settings [show|telemetry on|off|analytics on|off|crash-reports on|off]
    --action                   string    可选   隐私设置操作  取值: show/telemetry/analytics/crash-reports  默认=show
    --value                    string    可选   设置值 on/off,仅在 action=telemetry/analytics/crash-reports 时使用  取值: on/off

  /trust — 管理工作区信任目录
    用法: /trust [add|remove|list|clear]
    --action                   string    可选   信任目录操作  取值: add/remove/list/clear  默认=list

  /bridge — Bridge 远程控制管理
    用法: /bridge [qr|sessions|status|connect|disconnect]
    别名: /rc
    --action                   string    可选   Bridge 操作: qr=显示二维码, sessions=列出会话, status=状态, connect=连接, disconnect=断开  取值: qr/sessions/status/connect/disconnect

  /bridge-kick — 断开指定Bridge连接
    用法: /bridge-kick [session-id]
    --session-id               string    必填   要断开的 Bridge 会话 ID

  /peers — 列出对等节点
    用法: /peers
    别名: /remote
    (无结构化参数)

  /add-dir — 添加额外的工作目录
    用法: /add-dir <path> [--remember]
    --path                     string    必填   要添加的工作目录路径
    --remember                 boolean   可选   是否记住此目录供后续会话使用  默认=false

  /analyze — 分析代码
    用法: /analyze <代码>
    --code                     string    必填   要分析的代码内容

  /voice — 切换语音输入模式
    用法: /voice [on|off|status]
    --action                   string    可选   语音操作  取值: on/off/status/start/stop/record

  /copy — 复制最近的 AI 回复到剪贴板（/copy N 复制第N条）
    用法: /copy [N|code]
    --target                   string    可选   复制目标：N=第N条助手消息(1=最新)，code=最近代码块  取值: code/c/1/2/3

  /debuglog — 显示运行流程全貌（初始化|警告|错误|日志|系统提示词）
    用法: /debuglog [-a|-e|-w|-i|-p|-l|-c]
    --flags                    string    可选   显示标志（可组合）  取值: -a/--all/-e/--error/-w/--warn/-i/--init/-p/--prompt/-l/--log/-c/--clear

  /diag — 查看崩溃快照和诊断信息
    用法: /diag [recent|fence <name>|ack <id>|clear]
    --action                   string    可选   诊断操作  取值: recent/fence/ack/detail/clear
    --name                     string    可选   fence 围栏名 / ack|detail 快照 ID

  /export — 导出对话到文件或剪贴板
    用法: /export [filename|--clipboard]
    --target                   string    可选   导出目标：文件名或 --clipboard  取值: --clipboard

  /heapdump — 生成堆转储用于诊断
    用法: /heapdump
    (无结构化参数)

  /statusline — 切换状态栏显示
    用法: /statusline [on|off|format]
    --action                   string    可选   状态栏操作  取值: on/enable/off/disable/format
    --template                 string    可选   format 操作时的模板（变量: {model} {tokens} {cost} {mode} {time}）

  /summary — 显示当前会话摘要
    用法: /summary
    (无结构化参数)

  /tag — 为当前会话添加或管理标签
    用法: /tag [add|remove|list] [tag_name]
    --action                   string    可选   标签操作  取值: add/remove/list
    --tag_name                 string    可选   标签名称

  /upgrade — 检查并执行自升级
    用法: /upgrade [check|force|download|apply|auto]
    --action                   string    可选   升级操作  取值: check/force/download/apply/auto

  /workflows — 管理工作流
    用法: /workflows [list|run|status] [name]
    --action                   string    可选   工作流操作  取值: list/run/status
    --name                     string    可选   run 工作流名 / status 工作流 ID

  /goal — 目标自主循环引擎 — GoalSpec 收集模式（LLM 询问 6 字段后自主工作）
    用法: /goal [初始提示] [--constraint '约束'] [--budget <token数>] | /goal pause | /goal resume | /goal clear | /goal --cron <表达式> <描述>
    --subcommand               string    可选   生命周期子命令,省略时进入 GoalSpec 收集模式或显示状态  取值: pause/resume/clear/stop/off/reset/cancel
    --objective                string    可选   目标描述/初始提示,作为自主循环的目标
    --constraint               array     可选   约束条件,可多次指定 --constraint
    --budget                   number    可选   Token 预算上限
    --cron                     string    可选   Cron 表达式(5 字段),启用定时目标模式

  /proactive — 主动执行模式
    用法: /proactive [on|off|pause|resume|status]
    --action                   string    可选   主动模式动作(别名: on=activate/1, off=deactivate/0, status=s, pause=p, resume=r),省略时等同 status  取值: on/off/pause/resume/status  默认=status

  /tasks — 列出和管理后台任务
    用法: /tasks [kill|detail|create|update|complete|todo]
    别名: /task, /bashes
    --action                   string    可选   任务操作  取值: kill/detail/create/update/complete/todo

  /hooks — 管理 Hook 配置
    用法: /hooks [list|add|remove|test] [args]
    --action                   string    可选   Hook 操作  取值: list/add/remove/test
    --args                     string    可选   操作特定参数,如 add 的 Hook 配置

  /install — 让 AI 执行安装任务
    用法: /install <package-or-command>
    --package                  string    必填   要安装的包名或命令

  /install-github-app — 设置 JoinCode GitHub Actions 工作流
    用法: /install-github-app
    (无结构化参数)

  /mcp — 管理 MCP 服务器
    用法: /mcp [list|status|add|remove|reconnect|enable|disable] [args]
    --action                   string    可选   MCP 管理操作  取值: list/status/add/remove/reconnect/enable/disable
    --args                     string    可选   操作参数（add/remove 时为服务器名或配置 JSON）

  /plugin — 管理插件
    用法: /plugin [list|install|uninstall|enable|disable] [name]
    别名: /plugins, /marketplace
    --action                   string    可选   插件操作  取值: list/install/uninstall/enable/disable
    --name                     string    可选   插件名称

  /skills — 查看可用技能（自定义命令）
    用法: /skills [info <skill-name>]
    --action                   string    可选   操作,目前仅支持 info(查看技能详情)  取值: info
    --skill-name               string    可选   技能名称,仅在 action=info 时使用

  /tools — 显示可用工具列表
    用法: /tools
    (无结构化参数)

描述来源: 现有 [ChatCommand] / [ChatCommandArg] 特性，由本脚本在编译期提取。

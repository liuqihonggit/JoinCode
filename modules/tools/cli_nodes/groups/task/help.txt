jcc-tool-task — task 工具分组（12 个工具）

用法:
  jcc-tool-task.exe <工具名> [参数...]
  jcc-tool-task.exe -h
  jcc-tool-task.exe <工具名> -h

工具列表（说明复用自 [McpTool] 特性）:
  task_output                        Get output result of a background task
  task_stop                          Stop a running background task by ID
  task_stop_batch                    Stop multiple running tasks
  task_list_running                  List all running tasks
  task_create                        Create a new task
  task_list                          List tasks with optional filters
  task_update                        Update task information
  task_get                           Get task details
  task_set_dependency                Set a task dependency
  task_remove_dependency             Remove a task dependency
  task_get_dependencies              Get task dependency list
  task_can_execute                   Check if a task can execute (dependencies satisfied)

单个工具的参数说明:

  task_output — Get output result of a background task
    --task_id                    string    必填   Task ID
    --output_type                string    可选   Output type: stdout/stderr/all (optional, default all)  默认=all
    --max_lines                  integer   可选   Maximum output lines (optional, default 100)  默认=100

  task_stop — Stop a running background task by ID
    --task_id                    string    必填   The ID of the background task to stop
    --shell_id                   string    可选   Deprecated: use task_id instead (KillShell compat)

  task_stop_batch — Stop multiple running tasks
    --task_ids                   string    必填   Comma-separated task IDs

  task_list_running — List all running tasks
    --type                       string    可选   Filter by type: task/agent/all  默认=all

  task_create — Create a new task
    --title                      string    必填   Task title
    --description                string    可选   Task description (optional)
    --assignee                   string    可选   Assignee (optional)
    --due_date                   string    可选   Due date (optional)
    --priority                   string    可选   Priority: low, medium, high, default medium  默认=TodoPriorityEnumConstants.Medium
    --tags                       string    可选   Tag list (optional)

  task_list — List tasks with optional filters
    --status                     string    可选   Status filter (optional)
    --assignee                   string    可选   Assignee filter (optional)
    --priority                   string    可选   Priority filter (optional)
    --limit                      integer   可选   Result count limit, default 20
    --offset                     integer   可选   Offset for pagination

  task_update — Update task information
    (无参数)

  task_get — Get task details
    --task_id                    string    必填   Task ID

  task_set_dependency — Set a task dependency
    --task_id                    string    必填   Task ID
    --depends_on_task_id         string    必填   Depends-on task ID
    --dependency_type            string    可选   Dependency type: blocks, soft, subtask, default blocks

  task_remove_dependency — Remove a task dependency
    --task_id                    string    必填   Task ID
    --depends_on_task_id         string    必填   Depends-on task ID

  task_get_dependencies — Get task dependency list
    --task_id                    string    必填   Task ID

  task_can_execute — Check if a task can execute (dependencies satisfied)
    --task_id                    string    必填   Task ID

描述来源: 现有 [McpTool] / [McpToolParameter] 特性，由本脚本在编译期提取。

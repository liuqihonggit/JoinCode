jcc-tool-team — team 工具分组（10 个工具）

用法:
  jcc-tool-team.exe <工具名> [参数...]
  jcc-tool-team.exe -h
  jcc-tool-team.exe <工具名> -h

工具列表（说明复用自 [McpTool] 特性）:
  team_create                        Create a new team
  team_delete                        Delete a team
  team_get                           Get team information
  team_list                          List all teams
  team_add_member                    Add team member
  team_remove_member                 Remove team member
  team_send_message                  Send team message
  team_send_direct_message           Send direct message to specified agent
  team_broadcast                     Broadcast message to team members
  team_get_messages                  Get team message history

单个工具的参数说明:

  team_create — Create a new team
    --team_name                  string    必填   Team name
    --description                string    可选   Team description (optional)
    --initial_members            string    可选   Initial member list (optional)

  team_delete — Delete a team
    --team_id                    string    必填   Team ID

  team_get — Get team information
    --team_id                    string    必填   Team ID

  team_list — List all teams
    (无参数)

  team_add_member — Add team member
    --team_id                    string    必填   Team ID
    --agent_id                   string    必填   Agent ID

  team_remove_member — Remove team member
    --team_id                    string    必填   Team ID
    --agent_id                   string    必填   Agent ID

  team_send_message — Send team message
    --team_id                    string    必填   Team ID
    --sender_id                  string    必填   Sender ID
    --content                    string    必填   Message content
    --message_type               string    可选   Message type (optional)

  team_send_direct_message — Send direct message to specified agent
    --target_agent_id            string    必填   Target agent ID
    --sender_id                  string    必填   Sender ID
    --content                    string    必填   Message content
    --message_type               string    可选   Message type (optional)

  team_broadcast — Broadcast message to team members
    --team_id                    string    必填   Team ID
    --sender_id                  string    必填   Sender ID
    --content                    string    必填   Message content
    --message_type               string    可选   Message type (optional)

  team_get_messages — Get team message history
    --team_id                    string    必填   Team ID
    --limit                      integer   可选   Message count limit (optional, default 50)

描述来源: 现有 [McpTool] / [McpToolParameter] 特性，由本脚本在编译期提取。

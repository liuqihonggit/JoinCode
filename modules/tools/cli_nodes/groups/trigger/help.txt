jcc-tool-trigger — trigger 工具分组（1 个工具）

用法:
  jcc-tool-trigger.exe <工具名> [参数...]
  jcc-tool-trigger.exe -h
  jcc-tool-trigger.exe <工具名> -h

工具列表（说明复用自 [McpTool] 特性）:
  remote_trigger                     Manage remote triggers (list/get/create/update/run)

单个工具的参数说明:

  remote_trigger — Manage remote triggers (list/get/create/update/run)
    --action                     string    可选   Action type: list/get/create/update/run  默认=list
    --trigger_id                 string    可选   Trigger ID (required for get/update/run)
    --body                       string    可选   Trigger config (JSON format, optional for create/update)

描述来源: 现有 [McpTool] / [McpToolParameter] 特性，由本脚本在编译期提取。

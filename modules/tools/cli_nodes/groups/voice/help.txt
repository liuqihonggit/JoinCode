jcc-tool-voice — voice 工具分组（4 个工具）

用法:
  jcc-tool-voice.exe <工具名> [参数...]
  jcc-tool-voice.exe -h
  jcc-tool-voice.exe <工具名> -h

工具列表（说明复用自 [McpTool] 特性）:
  voice_start_recording              Start voice recording
  voice_stop_recording               Stop voice recording and return result
  voice_transcribe                   Transcribe audio file
  voice_status                       Get voice service status

单个工具的参数说明:

  voice_start_recording — Start voice recording
    (无参数)

  voice_stop_recording — Stop voice recording and return result
    (无参数)

  voice_transcribe — Transcribe audio file
    --file_path                  string    必填   Audio file path
    --language                   string    可选   Language code (optional, e.g. zh/en)

  voice_status — Get voice service status
    (无参数)

描述来源: 现有 [McpTool] / [McpToolParameter] 特性，由本脚本在编译期提取。

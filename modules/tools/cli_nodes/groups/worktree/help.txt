jcc-tool-worktree — worktree 工具分组（8 个工具）

用法:
  jcc-tool-worktree.exe <工具名> [参数...]
  jcc-tool-worktree.exe -h
  jcc-tool-worktree.exe <工具名> -h

工具列表（说明复用自 [McpTool] 特性）:
  worktree_create                    Create a Git Worktree isolated environment for an agent
  worktree_remove                    Remove an agent's Git Worktree
  worktree_list                      List all active Worktree sessions
  worktree_status                    Get detailed status of an agent's Worktree
  worktree_cleanup                   Clean up stale Worktree sessions
  worktree_find_git                  Find the Git repository root directory for a given path
  worktree_list_all                  List all Worktrees in a Git repository
  worktree_merge                     Merge a source Worktree changes into a target Worktree

单个工具的参数说明:

  worktree_create — Create a Git Worktree isolated environment for an agent
    --agent_id                   string    必填   Agent ID
    --git_root                   string    可选   Git repository root directory (optional, auto-detected)
    --base_branch                string    可选   Base branch or commit (optional)

  worktree_remove — Remove an agent's Git Worktree
    --agent_id                   string    必填   Agent ID
    --force                      boolean   可选   Force remove (even with uncommitted changes)

  worktree_list — List all active Worktree sessions
    (无参数)

  worktree_status — Get detailed status of an agent's Worktree
    --agent_id                   string    必填   Agent ID

  worktree_cleanup — Clean up stale Worktree sessions
    --stale_hours                integer   可选   Stale timeout in hours (default 24)
    --confirm                    string    必填   Confirm execution (enter 'yes' to confirm)

  worktree_find_git — Find the Git repository root directory for a given path
    --start_path                 string    可选   Start path (optional, defaults to current directory)

  worktree_list_all — List all Worktrees in a Git repository
    --git_root                   string    可选   Git repository root directory (optional, auto-detected)

  worktree_merge — Merge a source Worktree changes into a target Worktree
    --source_worktree_path       string    必填   Source worktree path (the worktree whose changes will be merged)
    --target_worktree_path       string    必填   Target worktree path (the worktree to merge changes into)
    --strategy                   string    可选   Merge strategy: fail, ours, theirs, auto_merge

描述来源: 现有 [McpTool] / [McpToolParameter] 特性，由本脚本在编译期提取。
